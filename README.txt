SYSTEMIZA — OFFLINE STATIC WEBSITE

1. Extract the complete ZIP file.
2. Open index.html directly in your browser.

No local server, Node.js, build command, or installation is required.
Keep the included folders and files together so page navigation and assets continue to work.

The website itself is self-contained, including Titillium Web fonts, images, icons, CSS, and JavaScript. Deliberate outbound links to social media and Google Maps require an internet connection.

The enquiry and demo forms are interface previews and do not transmit information until a secure submission service is configured.
